### What I'm building

**Codivaro** (launching soon at codivaro.de) is my software studio in Karlsruhe.
I build websites, online shops, ordering systems, iOS/Android apps, business
software and AI automation for small and mid-sized companies. One developer, a
direct line, no call centre, and the code belongs to the client.

**[NEXORA](https://github.com/msertdev/nexora)** is an Apache-2.0 self-hosted
workspace for projects, issues and team delivery: a Next.js 16 web app, a NestJS
API, PostgreSQL and Prisma in a TypeScript monorepo, deployed with Docker Compose
and Caddy. The next milestone is **NEXORA AI Agent v1**. Contributions are
welcome, see the [good first issues](https://github.com/msertdev/nexora/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).

**[Kelyvaro](https://kelyvaro.com)** is a live product that helps people in
Turkey apply directly to German employers. It matches openings from employer
career sites, prepares a German CV and cover letter for each role, and sends only
after the user approves the application.

### Engineering principles

- **Evidence before confidence.** Structured extraction carries source evidence
  and deterministic replay; unsupported values do not silently enter strict results.
- **Consent is an architectural boundary.** Nothing that leaves the system or
  moves money happens without explicit human approval.
- **Security belongs in the default path.** Database-backed sessions,
  server-enforced roles, origin validation, protected CI, CodeQL and secret scanning.
- **Failures stay explicit.** Integrations distinguish empty results from access,
  rate-limit, permission and format failures.
- **Measurements keep their limits.** Experiments publish sample sizes and leave
  untested findings visibly untested.
